# Student Attendance System

A complete web-based **Student Attendance Management System** built using **HTML, CSS, PHP, and SQL** as part of a database course project. The system allows students and teachers to manage attendance records efficiently with features like login/signup, role-based dashboards, attendance marking, and history tracking.

---

## 🌐 Tech Stack

- **Frontend**: HTML, CSS
- **Backend**: PHP
- **Database**: MySQL


---

## 🔑 Features

### 👤 Authentication
- Student and Teacher **Login/Signup**
- Secure login system with role-based access

### 👨‍🏫 Teacher Dashboard
- Add/View/Delete students
- Mark daily attendance
- View attendance history per student

### 👨‍🎓 Student Dashboard
- View attendance records
- Personal profile management
